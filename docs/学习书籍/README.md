## 一句话认识这个项目

**freqtrade 是一个开源的加密货币自动交易机器人**：它负责连交易所、拉 K 线、按你的策略发买卖信号、下单、记账、发通知；
你只需要写好中间那一步——**"什么时候买、什么时候卖"的策略**（`freqtrade/templates/sample_strategy.py` 就是最好的起点）。

> ⚠️ 免责声明：本项目仅供学习。所有策略在真金白银之前必须先跑模拟盘（`dry_run: true`）和回测。
