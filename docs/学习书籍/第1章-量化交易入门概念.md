# 第 1 章 量化交易入门概念

> 本章不写代码，先把后面五章要用到的"行话"讲明白。全部概念都会在 freqtrade 源码中出现。

---

## 1.1 什么是量化交易

**量化交易** = 把交易规则写成明确的、可执行的规则，由程序代替人执行。

人肉交易：看盘 → 感觉要涨 → 手动买入 → 感觉要跌 → 手动卖出（情绪 + 手速）。
量化交易：规则（如"RSI 低于 30 买入"）→ 程序每 5 分钟检查一次 → 满足条件自动下单（纪律 + 速度）。

freqtrade 就是执行框架，而**规则本身（策略）由你来写**。

## 1.2 K 线（蜡烛图）与 OHLCV

交易所每过一段时间就产出一根 **K 线**。一根 5 分钟 K 线包含 6 个数：

| 字段 | 含义 |
|---|---|
| `date` | 这根 K 线的开始时间 |
| `open` | 该时段第一笔成交价 |
| `high` | 该时段最高价 |
| `low` | 该时段最低价 |
| `close` | 该时段最后一笔成交价 |
| `volume` | 该时段成交量 |

在 freqtrade 里这 6 列构成一张 pandas 表格 `DataFrame`，简称"df"，策略代码全程都在操作它。
策略中的 `timeframe = "5m"`（`templates/sample_strategy.py:85`）就是"每 5 分钟一根 K 线"。

**周期**：`1m / 5m / 15m / 1h / 4h / 1d`……短周期信号多而噪，长周期信号少而稳。

## 1.3 技术指标（Indicator）

技术指标 = 对历史 OHLCV 做数学计算得到的数。示例策略用到的（`templates/sample_strategy.py`）：

| 指标 | 直觉理解 | 代码 |
|---|---|---|
| **RSI** 相对强弱 | 0~100。<30 算"超卖"（可能要反弹），>70 算"超买"（可能要回落） | `ta.RSI(dataframe)`（第 201 行） |
| **EMA/TEMA/SMA** 均线 | 最近 N 根的平均价平滑曲线，用来判断趋势方向 | `ta.TEMA(...)`（第 290 行） |
| **布林带** | 中轨=20 根均线，上下轨=±2 个标准差，价格碰下轨算"便宜" | `qtpylib.bollinger_bands(...)`（第 243 行） |
| **MACD** | 快慢均线差值，金叉看涨、死叉看跌 | `ta.MACD(...)`（第 228 行） |
| **SAR** | 抛物线转向，点在价格下方=多头、上方=空头 | `ta.SAR(...)`（第 287 行） |

指标没有"正确答案"，它们只是把价格/成交量换一个角度描述。**策略 = 若干指标条件的组合**。

## 1.4 做多、做空、交易对

- **交易对（pair）**：如 `BTC/USDT`，用 USDT 买卖 BTC。前者叫基础币，后者叫报价币。
- **做多（long）**：先买后卖，**赚上涨的钱**。低买高卖。
- **做空（short）**：先借卖出后买回归还，**赚下跌的钱**。高卖低买。策略里 `can_short = True` 才允许（现货 spot 不允许做空，合约 futures 允许）。
- freqtrade 的信号列也因此有四个：`enter_long`、`enter_short`、`exit_long`、`exit_short`（见第 3 章）。

## 1.5 下单类型

| 类型 | 英文 | 含义 |
|---|---|---|
| 限价单 | limit | 只在指定价格或更好价格成交，**可能一直不成交** |
| 市价单 | market | 立即按市场价成交，**保证成交但价格有滑点** |
| 止损单 | stoploss (stop market) | 价格跌到阈值自动市价卖出，用来"截断亏损" |

示例策略的配置（`templates/sample_strategy.py:107-112`）：入场/出场用 limit，止损用 market——止损要保证一定成交，速度优先于价格。

**手续费（fee）**：交易所每笔抽成（如 0.1%），买卖各收一次。回测必须计入手续费，否则结果虚高。

## 1.6 风控三件套：止盈、止损、仓位

1. **止损（stoploss）**：亏损到一定程度必须离场。策略里写 `stoploss = -0.10` 表示**亏 10% 就砍**（负号必须带，`sample_strategy.py:76`）。
2. **止盈（ROI）**：赚到目标就落袋。`minimal_roi`（`sample_strategy.py:67-72`）：
   ```python
   minimal_roi = {
       "60": 0.01,   # 持仓 60 分钟后，利润 ≥1% 就卖
       "30": 0.02,   # 30 分钟后 ≥2% 就卖
       "0":  0.04,   # 任何时候 ≥4% 就卖
   }
   ```
   键是"持仓分钟数"，值是"最小利润率"，框架自动匹配**最宽松的一条**。
3. **移动止损（trailing stop）**：价格涨了，止损线跟着抬高，锁住浮盈。`trailing_stop = True` 开启。
4. **仓位管理**：每笔投多少钱。配置里 `stake_amount: "unlimited"` + `max_open_trades: 3` 表示"总资金三等分，最多同时 3 笔"（计算逻辑见第 5 章 `wallets.py`）。

> 量化第一课：**先想亏多少，再想赚多少。** 没有风控的策略回测再漂亮都是空中楼阁。

## 1.7 回测、模拟盘、实盘

| 模式 | 含义 | freqtrade 用法 |
|---|---|---|
| **回测 backtest** | 用历史 K 线"重放"策略，秒级跑完几个月 | `freqtrade backtesting` |
| **模拟盘 dry-run** | 实时行情，**虚拟下单**，零风险体验全流程 | 配置 `"dry_run": true`（你现在 `user_data/config.json` 就是 true） |
| **实盘 live** | 真实资金真下单 | `"dry_run": false` + 填交易所 API key |

正确路径永远是：**回测 → 模拟盘（至少数周）→ 小资金实盘**。

## 1.8 量化新手必须知道的 5 个坑

1. **过拟合（overfitting）**：参数调到在历史数据上"完美"，实盘立刻失效。因为你调的是过去的噪音。对策：参数尽量少、用样本外数据验证（第 4 章）。
2. **未来函数（lookahead bias）**：不小心用了"未来才知道的数据"（比如用整根 K 线的收盘价去判断同一根 K 线的开盘时刻该不该买）。回测暴赚、实盘必亏。freqtrade 提供 `freqtrade lookahead-analysis` 命令专门检测。
3. **幸存者偏差**：只在"现在还活着的币"上回测，忽略已归零的币。
4. **滑点与流动性**：回测假设按理想价格成交，实盘小币种可能买不到/卖不掉。
5. **手续费侵蚀**：频繁交易时 0.1%×2 的手续费足以吃掉全部利润。

## 1.9 本章行话速查表

```
K线/OHLCV → DataFrame(表格) → 指标(列) → 信号(enter/exit 列)
做多long/做空short → 交易对pair → 限价单limit/市价单market
止损stoploss / 止盈ROI / 移动止损trailing → 仓位stake
回测backtest → 模拟盘dry-run → 实盘live
过拟合 / 未来函数 / 滑点 / 手续费
```
