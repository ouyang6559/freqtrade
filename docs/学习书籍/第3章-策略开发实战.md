# 第 3 章 策略开发实战

> 策略是你唯一需要亲手写的东西。本章以官方示例 `freqtrade/templates/sample_strategy.py` 为教材，逐段讲透。

---

## 3.1 策略是什么：三个函数 + 一堆配置

一个策略 = 继承 `IStrategy` 的类，**必须实现 3 个方法**（抽象方法，`strategy/interface.py:235` 起）：

| 方法 | 职责 | 类比 |
|---|---|---|
| `populate_indicators(df, meta)` | 往表格里**加指标列** | 备料 |
| `populate_entry_trend(df, meta)` | 决定**何时进场**（写 `enter_long`/`enter_short` 列） | 开火条件 |
| `populate_exit_trend(df, meta)` | 决定**何时离场**（写 `exit_long`/`exit_short` 列） | 撤退条件 |

外加类属性做配置：`timeframe`、`minimal_roi`、`stoploss`、`trailing_stop`……

框架什么时候调它们？在 `process()` 第 ⑦ 步 `strategy.analyze()` 时（第 2 章），对白名单里每个币：
`advise_indicators` → `advise_entry` → `advise_exit`（`interface.py:1817/1842/1861`），依次就是上面三个函数。

## 3.2 逐行精读：类属性（配置区）

`templates/sample_strategy.py:60-131`：

```python
INTERFACE_VERSION = 3        # 策略接口版本，写 3 才支持做空/杠杆
can_short: bool = False      # 是否允许做空（现货必须 False）

minimal_roi = {              # 止盈表：分钟数 -> 最小利润率
    "60": 0.01, "30": 0.02, "0": 0.04,
}
stoploss = -0.10             # 硬止损：-10%（必须是负数！）
trailing_stop = False        # 移动止损开关
timeframe = "5m"             # 策略主周期
process_only_new_candles = True   # 只在新K线出现时重算指标（省CPU）

use_exit_signal = True       # 是否使用 populate_exit_trend 的信号
exit_profit_only = False     # True = 亏损时忽略卖出信号（只在盈利时才听信号）
ignore_roi_if_entry_signal = False

buy_rsi = IntParameter(low=1, high=50, default=30, space="buy",
                       optimize=True, load=True)   # ★ 可被 hyperopt 优化的参数
sell_rsi = IntParameter(low=50, high=100, default=70, space="sell",
                        optimize=True, load=True)

startup_candle_count: int = 200  # 指标预热：先给策略 200 根历史K线

order_types = {              # 下单方式
    "entry": "limit", "exit": "limit",
    "stoploss": "market",    # 止损必须市价，抢速度
    "stoploss_on_exchange": False,  # True = 止损单挂在交易所，断网也生效
}
```

**新手默认照抄这些配置**，只需要理解 `minimal_roi`、`stoploss`、`timeframe` 三者。

## 3.3 逐行精读：`populate_indicators`

`sample_strategy.py:146-364`，模式高度统一——**算出指标 → 存成新列**：

```python
def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
    dataframe["adx"] = ta.ADX(dataframe)          # talib 算 ADX，加一列
    dataframe["rsi"] = ta.RSI(dataframe)          # 加一列 RSI

    macd = ta.MACD(dataframe)                     # MACD 一次给三列
    dataframe["macd"] = macd["macd"]
    dataframe["macdsignal"] = macd["macdsignal"]
    dataframe["macdhist"] = macd["macdhist"]

    bollinger = qtpylib.bollinger_bands(
        qtpylib.typical_price(dataframe), window=20, stds=2)
    dataframe["bb_lowerband"] = bollinger["lower"]
    dataframe["bb_middleband"] = bollinger["mid"]
    dataframe["bb_upperband"] = bollinger["upper"]

    dataframe["tema"] = ta.TEMA(dataframe, timeperiod=9)
    return dataframe        # ★ 必须把表返回去
```

要点：
- `metadata` 是 `{"pair": "BTC/USDT"}`，同一个函数会对每个币分别调用。
- `dataframe` 原始只有 `date/open/high/low/close/volume` 六列；本函数把它扩充到几十列。
- 注释掉的指标**故意不跑**——官方注释说得很清楚（第 150 行）：不用的指标别算，浪费内存和 CPU。

## 3.4 逐行精读：`populate_entry_trend`（核心语法）

`sample_strategy.py:366-395`，这是全项目**最值得背下来**的一段：

```python
def populate_entry_trend(self, dataframe, metadata) -> DataFrame:
    dataframe.loc[
        (
            (qtpylib.crossed_above(dataframe["rsi"], self.buy_rsi.value))  # ① RSI 上穿 30
            & (dataframe["tema"] <= dataframe["bb_middleband"])            # ② TEMA 在中轨下
            & (dataframe["tema"] > dataframe["tema"].shift(1))             # ③ TEMA 正在抬升
            & (dataframe["volume"] > 0)                                    # ④ 有成交量
        ),
        "enter_long",       # 满足全部条件的行
    ] = 1                   # 在 enter_long 列写 1（= 发出做多信号）
    return dataframe
```

逐条翻译成人话：
> "当 RSI 从下方突破 30（超卖反弹），同时价格还在布林中轨以下（不算追高），且短期均线开始拐头向上（趋势转暖），且成交量不为 0 —— 就买入做多。"

第二个 `dataframe.loc[...] = 1` 写的是 `"enter_short"`（RSI 上穿 70 + 中轨上方 + 均线拐头向下 → 做空）。

### pandas 信号三要素（新手必懂）

1. **`&` 是逐行的"与"**，每个条件必须加小括号（`&` 优先级高于 `==`），否则报错。
2. **`.shift(1)`** = 整列下移一行 = "上一根 K 线的值"，用于比较"和上一根比"。
3. **`.loc[条件, 列名] = 值`** = 批量赋值，等价于 Excel 里"筛选后填一列"。

### 四个信号列

| 列 | 含义 | 由谁消费 |
|---|---|---|
| `enter_long` | 开多 | `get_entry_signal`（`interface.py:1373`） |
| `enter_short` | 开空 | 同上，需 `can_short=True` 且非现货 |
| `exit_long` | 平多 | `get_exit_signal`（`interface.py:1321`） |
| `exit_short` | 平空 | 同上 |
| `enter_tag`/`exit_tag`（可选） | 给信号打标签，方便统计"哪种买法赚钱" | 报表分析 |

框架只看**最新一根 K 线**的这几列（`interface.py:1369` `get_latest_candle`）——所以你只管把条件写对，不用管"什么时候检查"。

## 3.5 `populate_exit_trend` 与出场三道闸

`sample_strategy.py:397-428` 写法与入场完全对称（RSI 上穿 70 → `exit_long`）。

但注意：**平仓时框架会同时检查三道闸**，任一触发即平（`interface.py:1419` `should_exit`，第 5 章详解）：

1. **退出信号**（你写的 `exit_long`）+ `custom_exit` 回调
2. **止损** `stoploss`（-10%）
3. **止盈** `minimal_roi`

所以策略可以只写入场、不写出场，靠 ROI+止损兜底；也可以三者都写。

## 3.7 多周期辅助：`@informative`

小周期看噪音、大周期看趋势。可以用装饰器给策略附加大周期数据：

```python
@informative('1h')                      # 额外提供 1 小时周期的数据
def populate_indicators_1h(self, dataframe, metadata) -> DataFrame:
    dataframe["ema_1h"] = ta.EMA(dataframe, timeperiod=50)
    return dataframe                    # 框架自动把结果合并回 5m 主表
```

限制：informative 周期必须 **≥ 主周期**（`interface.py:173` 有强制校验，违反直接报错）。

## 3.8 Hyperopt 参数：把魔法数字变成可搜索变量

```python
buy_rsi = IntParameter(low=1, high=50, default=30, space="buy")
# 之后代码里用 self.buy_rsi.value 而不是写死 30
```

- `space="buy"/"sell"/"exit"` 决定归入哪个搜索空间；
- 平时 `.value` 就是 `default`；跑 `freqtrade hyperopt` 时框架在 `[1,50]` 里搜索最优值（第 4 章）。
- 参数类型：`IntParameter`（整数）、`DecimalParameter`（小数）、`CategoricalParameter`（枚举选项）、`BooleanParameter`（真假）。

**原则：只有"你愿意让机器替你选"的数字才做成 Parameter，别把整个策略参数化。**

## 3.9 你的第一个策略（照抄改三行）

```python
# user_data/strategies/MyFirstStrategy.py
from freqtrade.strategy import IStrategy
from pandas import DataFrame
import talib.abstract as ta
from technical import qtpylib


class MyFirstStrategy(IStrategy):
    INTERFACE_VERSION = 3
    timeframe = "5m"
    stoploss = -0.10                 # 亏 10% 必砍
    minimal_roi = {"0": 0.10}        # 盈利 10% 就走（其余交给信号）
    can_short = False

    def populate_indicators(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        dataframe["rsi"] = ta.RSI(dataframe, timeperiod=14)
        dataframe["ema_fast"] = ta.EMA(dataframe, timeperiod=7)
        dataframe["ema_slow"] = ta.EMA(dataframe, timeperiod=25)
        return dataframe

    def populate_entry_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 快线上穿慢线（金叉）且 RSI 不在超买区 → 买入
        dataframe.loc[
            (
                (qtpylib.crossed_above(dataframe["ema_fast"], dataframe["ema_slow"]))
                & (dataframe["rsi"] < 70)
                & (dataframe["volume"] > 0)
            ),
            "enter_long",
        ] = 1
        return dataframe

    def populate_exit_trend(self, dataframe: DataFrame, metadata: dict) -> DataFrame:
        # 快线下穿慢线（死叉）→ 卖出
        dataframe.loc[
            (
                qtpylib.crossed_below(dataframe["ema_fast"], dataframe["ema_slow"])
                & (dataframe["volume"] > 0)
            ),
            "exit_long",
        ] = 1
        return dataframe
```
